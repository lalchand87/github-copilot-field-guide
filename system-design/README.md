# System Design — complete content

> Everything in SkillForge's System Design app, exported from the app's data on 2026-10-05. Start with the Curriculum, use the gyms for practice. Each file has its own contents list; `../SYSTEM_DESIGN.md` has everything in one file.

| Section | What is inside | File |
|---|---|---|
| Curriculum | 120 lessons in 15 categories. Each lesson: the 30-second version, the problem, mental model, how it works, a worked example, when to use / avoid, pros and cons, trade-offs, failure modes, limits, alternatives, real systems, common mistakes, the staff-level view, a deep dive and interview questions with model answers. | [01-curriculum.md](01-curriculum.md) |
| Pattern Gym | 70 patterns in 18 categories, each led by its trigger phrase ("When you hear…"): the problem, mental model, how it works (step-by-step request flows), technologies, trade-offs, failure modes, where it is used, how to present it in an interview, a practice drill and related patterns. | [02-patterns.md](02-patterns.md) |
| Drill Gym | 150 timed scenarios with constraints. Write your answer first, take the hints one at a time, then open the reference reasoning, trade-offs, staff-level view and follow-ups. | [03-drills.md](03-drills.md) |
| Workouts | 50 full system designs, each worked through in 9 stages (requirements, scale, API, data model, architecture, deep dives, failures, trade-offs, interview questions) plus the staff-level view — and 24 reusable end-to-end recipes. | [04-workouts.md](04-workouts.md) |
| Trade-off Gym | 54 paired choices. Make your call first, then compare both options on latency, throughput, consistency, complexity, cost and failure behaviour. | [05-tradeoffs.md](05-tradeoffs.md) |
| Failure Gym | 50 incidents. For each: the architecture, then impact, detection, mitigation, prevention and staff-level recovery. | [06-failures.md](06-failures.md) |
| Capacity Gym | 50 sizing scenarios. Estimate nine numbers yourself, then open the reference answers (with the working) to check. | [07-capacity.md](07-capacity.md) |
| Database Gym | 50 workloads. Note the access patterns, pick the primary store from four options, then open the reasoning and the staff-level view. | [08-database.md](08-database.md) |
| Pattern Recognition | 70 trigger phrases → building blocks (210 scenarios in the app: 3 rounds × 70 triggers). | [09-recognition.md](09-recognition.md) |
