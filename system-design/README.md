# System Design — complete content

> Everything in SkillForge's System Design app, exported from the app's data on 2026-10-05. Start with the Curriculum; use the gyms to practise. The content is split into files under 400 KB so GitHub can show every one of them.

Totals: 120 curriculum · 70 patterns · 150 drills · 50 systems · 54 tradeoffs · 50 failures · 50 capacity · 50 database · 24 recipes.

## Sections

| Section | What is inside |
|---|---|
| Curriculum | 120 lessons in 15 categories, one file per category. Each lesson: the 30-second version, the problem, mental model, how it works, a worked example, when to use / avoid, pros and cons, trade-offs, failure modes, limits, alternatives, real systems, common mistakes, the staff-level view, a deep dive and interview questions with model answers. |
| Pattern Gym | 70 patterns, each led by its trigger phrase ("When you hear…"): the problem, mental model, how it works (step-by-step request flows), technologies, trade-offs, failure modes, where it is used, how to present it in an interview, a practice drill and related patterns. |
| Drill Gym | 150 timed scenarios with constraints. Write your answer first, take the hints one at a time, then open the reference reasoning, trade-offs, staff-level view and follow-ups. |
| Workouts (designs) | 50 full system designs, each worked through in 9 stages: requirements, scale, API, data model, architecture, deep dives, failures, trade-offs and interview questions, plus the staff-level view. |
| Workouts (recipes) | 24 reusable end-to-end design flows: the brief, scale arithmetic, key decisions, a deep dive, how it fails and the staff-level view. |
| Trade-off Gym | 54 paired choices. Make your call first, then compare both options on latency, throughput, consistency, complexity, cost and failure behaviour. |
| Failure Gym | 50 incidents. For each: the architecture, then impact, detection, mitigation, prevention and staff-level recovery. |
| Capacity Gym | 50 sizing scenarios. Estimate nine numbers yourself, then open the reference answers (with the working) to check. |
| Database Gym | 50 workloads. Note the access patterns, pick the primary store from four options, then open the reasoning and the staff-level view. |
| Pattern Recognition | [09-recognition.md](09-recognition.md) — 70 trigger phrases → building blocks. |
